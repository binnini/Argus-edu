## 채점 프롬프트

### 시스템 프롬프트 (캐시 대상)

```
당신은 한국 고등학교 수학 채점 전문가입니다.
학생의 답변을 루브릭 기준에 따라 단계별로 채점하고, 반드시 아래 JSON 형식으로만 응답하세요.
수학적 사실에 근거하지 않는 내용은 절대 포함하지 마세요.
```

### 유저 프롬프트 템플릿

```
[문제]
{problem_content}

[정답]
{answer}

[참조 풀이]
{reference_solution}

[채점 루브릭]
{rubric_json}

[학생 답변]
{student_answer}

위 루브릭에 따라 학생 답변을 채점하세요. 반드시 아래 JSON 형식으로만 응답하세요.

{
  "total_score": <총점, 정수>,
  "steps": [
    {
      "step": <단계 번호>,
      "earned": <획득 점수, 정수>,
      "max": <최대 점수, 정수>,
      "reason": "<판단 근거, 1~2문장>"
    }
  ],
  "overall_comment": "<총평, 1~2문장>"
}
```

## 개인화 피드백 생성 프롬프트

학생의 **실제 오류**를 분석하고 어떻게 풀어야 했는지 교정 방향을 제시한다.  
일반적인 풀이 설명이 아니라, 이 학생이 틀린 부분에 집중한 맞춤형 피드백이어야 한다.

멀티 샘플링 3회 실행. 각 호출에 동일한 프롬프트 사용.  
`temperature=0.7` 권장 (불일치 탐지를 위해 약간의 다양성 필요).

### 시스템 프롬프트 (캐시 대상)

```
당신은 한국 고등학교 수학 교사입니다.
학생이 제출한 답변을 분석하여 무엇이 잘못되었고 어떻게 풀어야 했는지를 설명하세요.
- 학생이 맞게 한 부분은 간략히 인정하고, 틀린 부분에 집중하세요.
- 틀린 이유를 구체적으로 짚고, 올바른 풀이 방향을 단계별로 안내하세요.
- 수학적으로 정확한 내용만 작성하세요. 추측이나 불확실한 내용은 절대 포함하지 마세요.
```

### 유저 프롬프트 템플릿

```
[문제]
{problem_content}

[정답]
{answer}

[참조 풀이]
{reference_solution}

[채점 결과]
{grading_result_json}

[학생 답변]
{student_answer}

위 학생의 답변에서 무엇이 잘못되었고, 어떻게 풀었어야 하는지 설명하세요.
반드시 아래 JSON 형식으로만 응답하세요.

{
  "student_mistakes": [
    {
      "step": <채점 단계 번호>,
      "description": "<학생이 이 단계에서 무엇을 틀렸는지, 구체적으로>"
    }
  ],
  "correct_approach": [
    {
      "step": <단계 번호>,
      "title": "<단계 제목>",
      "content": "<올바른 풀이 설명>"
    }
  ],
  "key_concept": "<이 문제의 핵심 개념 또는 자주 하는 실수, 1~2문장>"
}
```

**주의**: `student_mistakes`는 채점에서 감점된 단계만 포함. 만점인 단계는 생략.  
`correct_approach`는 전체 풀이 단계를 포함 (학생이 맞춘 단계도 포함하여 흐름 유지).

## 불일치 탐지 로직

3회 생성된 피드백 간 불일치를 탐지한다.  
오류 식별과 교정 방향이 일관성 있게 제시됐는지를 측정한다.

```python
def calculate_inconsistency_rate(feedbacks: list[dict]) -> float:
    """
    3개 피드백의 correct_approach 단계 내용을 SBERT로 임베딩 후
    코사인 유사도 행렬 계산.
    - 유사도 < 0.85 구간을 불일치로 판정
    - 불일치 단계 수 / 전체 단계 수 = 불일치율
    """
```

## 종합 신뢰도 계산

```python
# hhem_score: 피드백이 reference_solution 기준으로 사실적으로 정확한가 (0~1)
# inconsistency_rate: 3회 생성 피드백 간 교정 방향의 불일치 비율 (0~1)
trust_score = 0.6 * hhem_score + 0.4 * (1 - inconsistency_rate)
trust_level = "high" if trust_score >= TRUST_THRESHOLD else "low"
```
