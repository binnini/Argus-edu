MVP 목표: 수능 수학 2~3점 서답형 유사 문제 15~20개.

  "answer": "1",
  "reference_solution": {
    "steps": [
      {
        "step": 1,
        "title": "도함수 계산",

      {
        "step": 2,
        "title": "임계점 탐색",
        "content": "f'(x) = 0 에서 x = 0 또는 x = 2. 구간 [0, 3] 내 임계점은 x = 0, 2"
      },
      {
        "step": 3,
        "title": "최솟값 결정",
        "content": "f(0) = 1, f(2) = 8 - 12 + 1 = -3, f(3) = 27 - 27 + 1 = 1. 최솟값은 f(2) = -3"
      }
    ]
  },
  "rubric": {
    "total_score": 3,
    "steps": [
      {"step": 1, "description": "도함수를 올바르게 계산", "score": 1},
      {"step": 2, "description": "구간 내 임계점을 모두 탐색", "score": 1},
      {"step": 3, "description": "경계값 포함 최솟값 정확히 도출", "score": 1}
    ]

  "test_answers": {
    "correct": "f'(x) = 3x² - 6x이고 f'(x) = 0에서 x = 0, 2. 각 점에서 f(0) = 1, f(2) = -3, f(3) = 1이므로 최솟값은 -3",

## 문제 확보 전략

### 1단계: Claude로 초안 생성

아래 프롬프트로 문제 초안을 일괄 생성한다.

```
수능 수학 2~3점 서답형 유사 문제를 생성하세요.
조건:
- 도메인: 수학2 (미분, 적분) 또는 확률과 통계
- 풀이 단계: 2~3단계
- 정답: 정수 또는 간단한 분수
- 저작권 없는 독창적 문제
- 위 JSON 스키마 형식으로 출력

문제 1개 생성해주세요.
```

### 2단계: 수동 검수 체크리스트

생성된 문제마다 아래를 확인한다.

- [ ] 정답이 수학적으로 올바른가
- [ ] reference_solution의 각 단계가 논리적으로 연결되는가
- [ ] rubric의 배점 합계 = total_score인가
- [ ] 수능 유형과 난이도가 일치하는가 (킬러 문항 제외)
- [ ] 기출문제와 유사하지 않은가 (저작권)

### 3단계: 도메인 분포 목표

| 도메인 | 문제 수 | 주제 |
|---|---|---|
| 수학2 — 미분 | 6 | 극값, 최솟값, 접선, 증감표 |
| 수학2 — 적분 | 4 | 정적분, 넓이, 속도-거리 |
| 확률과 통계 | 5 | 조합, 확률, 정규분포 |
| 예비 (OOM 대비) | 3 | 검수 탈락 시 대체용 |

## 테스트용 학생 답변 생성 전략

E2E 테스트에 사용할 학생 답변 샘플. 문제당 3종류.

| 유형 | 기대 채점 | 기대 신뢰도 | 목적 |
|---|---|---|---|
| 정답 | 만점 | High | 정상 흐름 검증 |
| 부분 정답 | 1~2점 | High or Low | 부분 점수 처리 검증 |
| 오답 (할루시네이션 유발) | 0점 | Low | 할루시네이션 탐지 검증 |

오답 유형은 의도적으로 수식 오류, 단계 누락, 엉뚱한 공식 적용 등을 포함한다.

## 파일 위치

```
data/
├── problems/
│   ├── math2_differentiation.json   # 수학2 미분 문제
│   ├── math2_integration.json       # 수학2 적분 문제
│   └── stats_probability.json       # 확률과 통계 문제
└── test_answers/
    └── sample_submissions.json      # E2E 테스트용 학생 답변 샘플
```

`data/` 폴더는 DB 시드 스크립트(`scripts/seed.py`)로 PostgreSQL에 삽입.
